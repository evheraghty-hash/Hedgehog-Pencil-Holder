# Hedgehog-Pencil-Holder
I made a 3D printed hedgehog where the spikes are holes to store pencils.

I made this for the Half-Life week 2 project run by Hackclub. I made it on Tinkercad as a beginner project.

This works by using the holes or empty spikes in the hedgehog as a place to hold pencils. It is functional and appealing at the same time!

I made two hedgehogs; one with an angry or tired expression and the other with a neutral expression.
